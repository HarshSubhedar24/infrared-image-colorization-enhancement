PROCESS A NEW SCENE

Run all processing stages with one scene selection:

C:\Python314\python.exe .\run_pipeline.py

The pipeline asks for the scene once, then runs these stages automatically:

1. RGB generation
2. Thermal preprocessing
3. ESRGAN inference using the shared checkpoint
4. Thermal alignment to the RGB grid
5. Four-channel Pix2Pix inference

The Windows folder picker opens automatically. Browse the entire device and
select the scene folder directly.

The new scene must contain:

..._SR_B2.TIF
..._SR_B3.TIF
..._SR_B4.TIF
..._ST_B10.TIF

Thermal preprocessing is run automatically for a new scene. The shared
ESRGAN model is reused; ESRGAN is not retrained for every scene.

The shared checkpoint must already exist in the project directory:

ESRGAN_Combined_Dataset\checkpoints\esrgan_epoch_0050.pt

If the shared checkpoint is stored beside the selected scene folders instead,
the pipeline detects it automatically. You can also set an explicit path:

$env:ESRGAN_CHECKPOINT_PATH = "C:\path\to\esrgan_epoch_0050.pt"

TRAIN THE SHARED ESRGAN MODEL

Run these commands once, or rerun them when the shared model needs updating.

1) Prepare one combined ESRGAN dataset from multiple preprocessed scenes

C:\Python314\python.exe .\prepare_combined_esrgan_dataset.py

This asks for the parent folder containing scenes and uses scenes containing:

Output\Thermal_PNG\Thermal_Image.png

2) Train ESRGAN once on the combined dataset

C:\Python314\python.exe .\train_esrgan.py

The checkpoint is saved to:

ESRGAN_Combined_Dataset\checkpoints\esrgan_epoch_0050.pt

PREPARE THE SHARED PIX2PIX DATASET

Use ten or more prepared scenes. Each scene must contain:

Output\Enhanced_Thermal\Enhanced_Thermal_Pix2Pix.tif
Output\RGB_Image.png

Run:

C:\Python314\python.exe .\prepare_combined_pix2pix_dataset.py

Select the parent folder containing the scene folders. The script requires
at least 10 valid scenes, keeps scenes (not individual patches) separated
between train, validation, and test, and writes:

Pix2Pix_Combined_Dataset\
    train\
        input_rgb\
        input_thermal\
        rgb\
    validation\
        input_rgb\
        input_thermal\
        rgb\
    test\
        input_rgb\
        input_thermal\
        rgb\
    dataset_manifest.json

TRAIN THE SHARED PIX2PIX MODEL

After the combined dataset has been created, train Pix2Pix once:

C:\Python314\python.exe .\train_pix2pix.py

The shared checkpoints are saved to:

D:\datasets\Pix2Pix_Combined_Dataset\checkpoints\pix2pix_best.pt
D:\datasets\Pix2Pix_Combined_Dataset\checkpoints\pix2pix_latest.pt
D:\datasets\Pix2Pix_Combined_Dataset\checkpoints\training_history.json

The scripts search for the shared dataset in this order:

1. PIX2PIX_DATASET_ROOT, when configured
2. D:\datasets\Pix2Pix_Combined_Dataset
3. Pix2Pix_Combined_Dataset inside the project directory

To use another location:

$env:PIX2PIX_DATASET_ROOT = "D:\path\to\Pix2Pix_Combined_Dataset"

The Pix2Pix input has four channels: visible B2/B3/B4 RGB values plus the
aligned enhanced thermal band. After changing from the previous thermal-only
model, regenerate the combined dataset and retrain Pix2Pix once.

ADDING NEW SCENES TO PIX2PIX TRAINING

An existing Pix2Pix checkpoint can process a new scene without retraining.
Run the normal new-scene pipeline, align the enhanced thermal image, and run:

C:\Python314\python.exe .\run_pix2pix_inference.py

If the new scene should contribute to model learning, rebuild the combined
dataset and retrain:

C:\Python314\python.exe .\prepare_combined_pix2pix_dataset.py
C:\Python314\python.exe .\train_pix2pix.py

The dataset builder recreates the combined dataset and may change the
scene-level train/validation/test split. Train from the beginning after this
rebuild rather than resuming an old checkpoint. Retraining is recommended for
new locations, seasons, cloud conditions, lighting, land-cover types, or poor
results on the new scenes.

PROCESSING COMMANDS

Run individual stages independently when rerunning one stage:

1) Prepare RGB image for the selected scene
C:\Python314\python.exe .\rgb_combine.py

2) Prepare thermal image for a new scene
C:\Python314\python.exe .\thermal_preprocessing.py

3) Run ESRGAN inference with the shared checkpoint
C:\Python314\python.exe .\run_esrgan_inference.py

4) Align enhanced thermal image to the RGB grid for Pix2Pix
C:\Python314\python.exe .\align_enhanced_thermal.py

5) Generate colorized RGB output with the shared Pix2Pix model
C:\Python314\python.exe .\run_pix2pix_inference.py

This uses:

Output\Enhanced_Thermal\Enhanced_Thermal_Pix2Pix.tif

and saves:

Output\Pix2Pix_Colorized_RGB.png
Output\Pix2Pix_Colorized_RGB.tif

Inference uses 256-pixel tiles with 64-pixel overlap and feathered
raised-cosine blending to reduce visible tile-grid seams. It preserves 70%
of the visible RGB input so clouds and fine visible details remain present.
NoData/background pixels from the aligned thermal raster remain black in the
output.

The per-scene processing scripts ask you to select a scene when started.
The combined Pix2Pix dataset script asks you to select the parent folder
containing the scenes, and the shared Pix2Pix training script uses the
project-level combined dataset without selecting a scene.

OPTIONAL: ADD A NEW SCENE TO FUTURE ESRGAN TRAINING

After thermal preprocessing has completed for the new scene, rebuild the
combined dataset:

C:\Python314\python.exe .\prepare_combined_esrgan_dataset.py

Then retrain the shared model:

C:\Python314\python.exe .\train_esrgan.py

This is optional. Do not run these commands just to process a new scene.
